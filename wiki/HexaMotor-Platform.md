# HexaMotor Platform

This page describes the advanced control experiments using the HexaMotor multi-axis motor platform, located in the `HexaMotor/` directory.

## HexaMotor_VelocityControl

Educational materials for velocity control implementation:

- **Motor Testing**: System characterization
- **System Identification**: Parameter estimation
- **Velocity Control**: Closed-loop speed regulation

See `HexaMotor/HexaMotor_VelocityControl/HexaMotor Velocity Control.pdf` for the full manual.

## HexaMotor_Force_FF

Feed-forward force control implementation for the HexaMotor platform.
